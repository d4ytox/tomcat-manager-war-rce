# Security policy

This repository holds a proof-of-concept for an authenticated WAR-upload to remote code execution on Apache Tomcat Manager. As the README explains, it uses the Manager application the way it is intended, with valid manager-gui credentials, so there is no single CVE for it. The technique maps to MITRE ATT&CK T1021, Remote Services. The code is published for security education and for authorised testing against systems you own or have written permission to test.

## Reporting

This is research material, not a maintained product, so there is no separate vulnerability-reporting process for this repository. Security issues in Apache Tomcat should go to the Apache Software Foundation at https://tomcat.apache.org/security.html.

## Intended use

For authorised testing and research only. Running this against a system you do not own, or do not have written permission to test, is illegal in most places.
